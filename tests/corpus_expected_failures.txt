# Schemas in the fetched corpus (tests/fetch_corpus.py) that rapidprotoc is KNOWN not to accept.
#
# Format: `<corpus-relative path><TAB><substring the error message must contain>`.
#
# The reason is MATCHED, not decoration: a listed schema that starts failing for a different
# reason is a regression the gate must catch, so the recorded substring has to appear in the
# actual error. The list is also bidirectional -- a listed schema that starts PASSING fails the
# gate too, so fixing a limitation deletes its lines in the same change and the list cannot rot
# into stale excuses.
#
# Keep it SMALL. Every line is a documented gap between RapidProto and protoc; if this file
# grows, that is the signal, not the noise.

# --- Editions whose feature defaults we do not know ---

# refused rather than assumed. This line goes away if UNSTABLE is ever pinned to a real edition we
# add to kKnownEditions (src/features.cpp) after checking its defaults.
